# Agent Working State

Before changing the project, read:

1. [`progress/global-knowledge.md`](progress/global-knowledge.md) for the current technical setup and constraints.
2. [`progress/progress.md`](progress/progress.md) for completed and pending work.
3. The newest numbered partition under [`progress/`](progress/) for the latest decisions, attempts, and validation evidence.

Add a new numbered partition for each substantial milestone. Each partition must contain `update.md` and `knowledge.md`, then update both global files after validation.
